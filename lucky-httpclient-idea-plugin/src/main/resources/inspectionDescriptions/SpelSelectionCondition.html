检查 SpEL 条件表达式的结果类型：选择（过滤）表达式 ?[...]、^[...]、$[...]，以及 @If#condition、@Retryable#condition 等条件属性。

下列属性按框架的布尔语义求值，同样参与检查：

  • 条件表达式：@If#condition、@Retryable#condition、 @AutoVerifyHttpStatus#condition、@Condition#assertion、 @ExceptionHandleMeta#condition；
  • 静态参数条件：@StaticQuery#condition、@StaticHeader#condition、 @StaticCookie#condition、@StaticPath#condition、 @StaticForm#condition、@StaticResource#condition、 @MultipartFormData#condition、@Binary#condition、 @FilePart#condition、@Txt#condition；
  • 开关属性：@Retryable#enable、@RetryMeta#enable、 @Condition#enable、@Hook#enable、@Plugin#enable、 @SSL#enable、@Mock#enable、@DestroyMeta#enable 等；
  • 日志条件：@PrintLog#reqCondition、@PrintLog#respCondition、 @AutoRedirect#condition。

Spring 求值过滤条件时要求结果是 boolean/Boolean， 其余类型会抛 SpelEvaluationException；条件属性最终也按布尔值 使用。能静态推导出确定类型且不是布尔时报告错误：

  • users.?[name]：条件结果是 String → error；
  • users.?[1]、users.?['x']：非布尔字面量 → error；
  • users.?[#this]：元素类型确定且不是布尔 → error；
  • @If(condition = "#{'abc'}")：条件结果是 String → error；
  • @If(condition = "#{1}")、condition = "1"：非布尔字面量 → error；
  • @StaticQuery(condition = "#{1}")、@Hook(enable = "#{'abc'}")： 非布尔条件 → error；
  • @If(condition = "#{1+2}")：算术表达式的结果是 Integer → error；
  • users.?[#this.age + '12']：与字符串拼接的结果是 String → error；
  • #{true}、condition = "false"、users.?[active]： 结果类型是 boolean/Boolean → 通过；
  • 比较与逻辑表达式（age > 1、#{1+2 == 3}、 #a != null、#a and #b、!(#a || #b)）： 结果一定是 boolean → 通过；
  • 条件类型无法推导（未知符号、未知类型的四则运算）、泛型类型变量、 ![...] 投影 → 保守放行，不报告。

条件内部的 #this 与裸标识符按当前元素类型解析，与成员检查、 补全共用同一套类型推导。条件属性由多个 #{...} 片段拼接时结果 一定是 String，同样报告错误。默认严重级别为错误，可在 Settings | Editor | Inspections | Lucky HttpClient SpEL 中调整级别或完全关闭。单条结果可用「抑制此提示」快速修复添加 @SuppressWarnings("SpelSelectionCondition")。
