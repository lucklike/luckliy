检查 SpEL 选择（过滤）表达式 ?[...]、^[...]、$[...] 的条件结果类型。

Spring 求值过滤条件时要求结果是 boolean/Boolean， 其余类型会抛 SpelEvaluationException。条件表达式能静态推导出 确定类型且不是布尔时报告错误：

  • users.?[name]：条件结果是 String → error；
  • users.?[1]、users.?['x']：非布尔字面量 → error；
  • users.?[#this]：元素类型确定且不是布尔 → error；
  • users.?[active]、users.?[true]：结果类型是 boolean/Boolean → 通过；
  • 条件类型无法推导（age > 1 这类二元表达式、未知符号）、 泛型类型变量、![...] 投影 → 保守放行，不报告。

条件内部的 #this 与裸标识符按当前元素类型解析，与成员检查、 补全共用同一套类型推导。默认严重级别为错误，可在 Settings | Editor | Inspections | Lucky HttpClient SpEL 中调整级别或完全关闭。单条结果可用「抑制此提示」快速修复添加 @SuppressWarnings("SpelSelectionCondition")。
