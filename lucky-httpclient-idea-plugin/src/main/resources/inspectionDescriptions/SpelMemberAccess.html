检查 SpEL 表达式在 .（含安全导航 ?.）之后的成员是否存在。

接收者类型能静态解析时，按真实类（含继承体系）校验成员：

  • 方法调用 user.m4()：类中不存在同名方法 → error；
  • 属性访问 user.d：类中不存在同名字段，也不存在 getD()/isD() 形式的 getter → error；
  • 接收者类型明确是 Object（例如未配置 @ConvertMetaType 的 $body$）→ warning，只提示无法静态校验，不断言错误；
  • Map 的成员是动态 key，不做校验；泛型类型变量、数组接收者 与无法推导类型的表达式保守放行。

成员检查与成员导航、补全共用同一套类型推导；$this$、 $result$、$body$ 等推导出确定类型的变量同样参与检查。 默认严重级别为错误，可在 Settings | Editor | Inspections | Lucky HttpClient SpEL 中调整级别或完全关闭。单条结果可用「抑制此提示」快速修复添加 @SuppressWarnings("SpelMemberAccess")。
